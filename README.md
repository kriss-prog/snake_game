# Modern Snake Pro 🐍

A sleek, modern, and highly polished Snake game built with Python and Pygame. This project focuses on delivering a visually appealing "game-feel" while keeping the underlying source code clean, efficient, and lightweight.

## ✨ Features

* **Procedural Graphics:** Built-in smooth styling! The snake body uses rounded corner segments, and the head features dynamic eyes that look in the direction you are traveling.
* **Google-Style Grid Layout:** Features a clean, alternating dark-and-light checkerboard playing map for enhanced spatial awareness.
* **Session High Score:** Tracks your personal best score dynamically at the top dashboard during your play session.
* **Progressive Difficulty:** The snake starts at a comfortable pace, but increases its movement speed (FPS) automatically for every 3 apples eaten to ramp up the tension.
* **Fluid WASD Controls:** Standardized PC gaming layout for movement.

---

## 🎮 How to Play

1. **Controls:** Use `W` (Up), `A` (Left), `S` (Down), and `D` (Right) to maneuver the snake.
2. **Objective:** Eat the pink apples to grow longer and increase your score.
3. **Avoid Collisions:** Game over occurs if you crash into the map boundaries or run into your own body.
4. **Restart:** Simply press **any key** on the Game Over screen to instantly start a new match.
